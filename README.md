# LookAI Pro

LookAI Pro, Gemini AI ve görsel analiz teknolojilerini kullanan, yerel uçtan uca şifreleme ile verilerinizi koruyan akıllı bir asistan uygulamasıdır.

## Özellikler
- 🔍 **Yapay Zeka Analizi:** Gemini Flash Vision ile nesne tanıma ve soru çözme.
- 🔬 **STEM Atölyesi:** Materyallerden proje fikirleri üretme.
- 🔐 **Güvenlik:** AES-256-GCM ile verilerinizi yerel olarak şifreleyerek koruma.
- 🔊 **Sesli Asistan:** Analiz sonuçlarını Türkçe sesli okuma.
- 📲 **Paylaşım:** Sonuçları WhatsApp üzerinden hızlıca paylaşma.

## Teknoloji Yığını (Tech Stack)
- **Framework:** React Native / Expo
- **AI Engine:** Google Gemini API
- **Güvenlik:** Web Crypto API (SubtleCrypto) & AsyncStorage
- **Build Service:** EAS Build (Android App Bundle - AAB)
